# Fantasy Battle — Sapphire Sumi integration
All 48 UI IDs have dedicated render cases. UI text is live HTML; the vector panel backgrounds are reconstructed text-free templates, not pixel-perfect retouches of concept art.
 
## Preview
With the branch checked out, run npm install and npm run dev, then visit /fantasy-battle. Production stays Coming Soon until the existing release flag is deliberately enabled following QA. The other games are unchanged.
 
The title leads to setup, character creation, selection, loading and Sapphire Wilds. Loading waits for world restore acknowledgement. Escape opens/closes pause; C character, K skillbook, M map, L journal, I equipment. Normal encounters launch the existing archer battle on the 3D Sapphire Sanctuary; elite/boss encounters show entrance and introduction first. Battle rewards and level-ups open real progression screens, then resume the world. The map reads the actual world section registry, streamed encounter markers and player coordinates; new regions in that registry flow through the UI, but separate future maps need registration.
 
## State and scope
Guest data is localStorage, three validated slots, separate namespace. No fabricated saves, no login restoration, no new public server endpoints. Cloud saves are not implemented. A validated portable JSON backup can be exported in Save Game or Load Game and imported from title Settings into a chosen slot with explicit confirmation. It is local-only, bounded to 512 KiB and strips unknown fields; no account or public server endpoint was added. The economy and skill thresholds are provisional prototype balancing. One prototype companion, Grove Archer, is recruitable after the first grove victory. Recruitment, formation and bond screens use real saved state. The companion shares the existing archer rig and a mint palette; unique models and narrative relationship events are still unauthored. Wardrobe now supports four stat-neutral color palettes applied to the existing archer rig, exploration placeholder avatar and portrait preview. These are color variations, not new clothing meshes. Legacy saves without an appearance field use Silver Archer. Boss encounters currently reuse the archer opponent with scaled stats, not a distinct boss model.
 
## Artwork
The revised 48 text-free vector frames, eight live item/skill icons, six optimized WebP backgrounds (five original clean paintings and the original title scene crop) and four decorative illustration extracts are committed directly on this branch. No separate asset installation is required. See public/fantasybattle/sapphire and tests/fantasybattle-sapphire-art.test.mjs.
The original title painting uses the text-free scenic right portion; the left navigation and all labels are rendered independently. Major event/loading/title screens have cinematic backgrounds; pause, gameplay HUDs and small overlays preserve the active 3D scene. The quest, skill and acquisition artwork is decorative, not a claim about the player's character or equipped item. Exact individually painted text removal from all 48 full reference images remains a separate art pass.

## Follow-up hardening
- Loading waits for the world restore acknowledgement; arena/combat startup now has a 30-second watchdog, and late ready messages cannot dismiss an error dialog. Error retry restarts from the saved exploration checkpoint. Movement input resets on blur and tab hiding.
- Character creation, selection, stats, wardrobe and combat HUD use the existing archer portrait, tinted from the same palette used in the combat rig. No duplicated portrait textures.
- Save import checks slot state again at confirmation; no overwrite is silently applied. Existing saved profiles remain compatible.
- Eight isolated logic test groups passed using a JS harness (UUID and UTF-8 byte-length shims); the modified stage and world JavaScript bodies parsed with static imports removed. The dedicated Fantasy Battle GitHub Actions workflow runs native Node tests and asset integrity checks; full build and browser validation remain required.

## Party and companion follow-up
- Unlock Grove Archer after defeating Whispering Grove Spirit; recruit from the party/recruitment screen. The prototype supports two player units versus one enemy, not full 4v4. The companion has 85 HP, 9 attack, 9 defense, 9 speed and Quick Shot, Triple Volley and Guard. These are provisional values; the name is a prototype placeholder, not established story canon.
- Set the frontline or move the companion to reserve outside combat. Enemy targeting follows the first living ally in formation. Each living ally chooses an action before the round resolves; enemy choices remain AI-controlled. A knocked-out ally is skipped. The existing shared archer rig renders both allies and the opponent; no new character model or class is claimed.
- New victories together award five bond points (maximum 100), and companion HP persists. Practice and repeated rewards do not advance bond. Sanctuary rest restores both recruited members. Legacy saves without a party field remain valid, and portable backups include validated party fields.
- Twelve gameplay regression groups and three additional stage-control checks passed in an isolated JS harness with renderer/animation stubbed. Native CI, actual rendered positioning/animations, mobile layout, security scanner and production build remain unverified. Test both formations, KO retargeting, pause/resume during selection, reserve, rest, reload, and portable saves in the live browser before release.
