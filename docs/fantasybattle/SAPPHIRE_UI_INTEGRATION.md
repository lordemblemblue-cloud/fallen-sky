# Fantasy Battle — Sapphire Sumi integration
All 48 UI IDs have dedicated render cases. UI text is live HTML; the vector panel backgrounds are reconstructed text-free templates, not pixel-perfect retouches of concept art.
 
## Preview
With the branch checked out, run npm install and npm run dev, then visit /fantasy-battle. Production stays Coming Soon until the existing release flag is deliberately enabled following QA. The other games are unchanged.
 
The title leads to setup, character creation, selection, loading and Sapphire Wilds. Loading waits for world restore acknowledgement. Escape opens/closes pause; C character, K skillbook, M map, L journal, I equipment. Normal encounters launch the existing archer battle on the 3D Sapphire Sanctuary; elite/boss encounters show entrance and introduction first. Battle rewards and level-ups open real progression screens, then resume the world. The map reads the actual world section registry, streamed encounter markers and player coordinates; new regions in that registry flow through the UI, but separate future maps need registration.
 
## State and scope
Guest data is localStorage, three validated slots, separate namespace. No fabricated saves, no login restoration, no new public server endpoints. Cloud saves are not implemented. A validated portable JSON backup can be exported in Save Game or Load Game and imported from title Settings into a chosen slot with explicit confirmation. It is local-only, bounded to 512 KiB and strips unknown fields; no account or public server endpoint was added. The economy and skill thresholds are provisional prototype balancing. Three prototype companions are recruitable after individual Sapphire Wilds victories. The four-member roster, formation and bond screens use real saved state. All share the existing archer rig with distinct palettes and combat roles; unique models, non-bow animation sets and narrative relationship events are still unauthored. Wardrobe now supports four stat-neutral color palettes applied to the existing archer rig, exploration placeholder avatar and portrait preview. These are color variations, not new clothing meshes. Legacy saves without an appearance field use Silver Archer. Boss encounters currently reuse the archer opponent with scaled stats, not a distinct boss model.

## Enemy-exclusive abilities and Gatekeeper phases
Registered enemy encounters use three normal archetypes (Spirit, Sentinel, Mist) and a Gatekeeper boss kit. Seven enemy-only actions: Spirit Bolt, Runic Ward, Mist Barrage, Celestial Lance, Starfall Volley, Eclipse Ray and Celestial Aegis. Gatekeeper phases are Astral Watch (>65% HP), Falling Stars (<=65%, >30%), Total Eclipse (<=30%). Phase is evaluated at round start; a crossing during an already committed round applies next round. Final phase charges Focus with Aegis before Eclipse Ray; Starfall is single-frontline three-hit, not area damage. HUD shows exact deterministic intent in the choose phase, including phase name, warning and target role (retargets if original frontline falls). Enemy-only kits cannot be granted to player units. Seven retimed ranged/ward clips use existing rig channels and projectile effects; no bespoke particle system or final motion art claimed. Original generic boss strategy stays available for non-registered test/practice encounters. Tuning, rendered hit synchronization and browser/native regression QA remain outstanding.
