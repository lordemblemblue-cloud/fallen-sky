# Game 3D / Book — Atom × Eve migration

## Source and destination
- **Exact source:** `marcusflow1-arch/atom-x-eve-os`, **Game 3D / Book**, with the **Adam and Eve** models. The separate `Game3.jsx` racing title is intentionally excluded.
- **Source main inspected:** `c073fc3be90b7013b1b5dae2da7f802b902675e2` (2026-11-12).
- **Destination:** `marcusflow1-arch/gitsync-pro`, TanStack Start / Cloudflare worker app.
- **Migration branch:** `migration/game3d-book-adam-eve-20261112` (not yet released to main).

## Changes already pushed to this migration branch
- 72 source files copied verbatim into their original paths, including `src/pages/GameView.jsx`, GameWorld3D, the original character login/creation, Adam/Eve model URL resolvers, character storage, creator controls and styles, faction mount registry, mounts/companions, Halo/Angel Wings, world entry/quest/HUD/social panels and key server / Base44 function and schema entry points.
- Removed the old **GitSync** dashboard routes (`/issues`, `/pull-requests`, `/repositories`) **on this branch**. The authenticated homepage points to the imported Game 3D component. Kept the app's auth/login routes, Base44 scripts, server entry, and TanStack Start router intact.
- Added the React Router compatibility dependency and Three.js / game runtime dependencies to `package.json`. A new lockfile must be generated by `npm install`; native build has **not** passed yet.
- Added `scripts/import-game3d-book.mjs`, a reproducible installer that clones the private source via authenticated `gh` (or uses `--source-dir`) and imports the **remaining** Game 3D frontend import graph, Node game server, relevant Base44 functions/entities, `public/game3d` assets and `public/models/characters` Adam/Eve GLBs. It preserves this destination's app framework and auth.

## Work not yet complete
The source repository has **922** `src/components/game3d/` files, **627** `server/game3d/` files, and additional cross-module dependencies. This branch presently includes **only an initial subset**, not a full runnable port. **The local binary character models and audio assets are not yet imported** (the GitHub connector cannot read private binary blobs and the current container cannot clone GitHub). Some source GLBs referenced by the faction registry are hosted in the original app's public media library; those are URLs, not vendored binaries.

The Node game server is a separate runtime and does not automatically execute in TanStack/Cloudflare. Base44 entities, backend functions, security permissions, secrets, live player data and server state are **not transferred just by copying GitHub code**. Do not blindly copy tokens or live customer/player records. The destination Base44 app is not currently accessible through this assistant's Base44 app list, so the connection and deployment have **not** been verified.

## Complete the source import in an authenticated local environment
```bash
gh repo clone marcusflow1-arch/gitsync-pro
cd gitsync-pro
git fetch origin migration/game3d-book-adam-eve-20261112
git switch migration/game3d-book-adam-eve-20261112
npm run migrate:game3d -- --apply
npm install
npm run build
```

The import command clones `marcusflow1-arch/atom-x-eve-os` directly and writes the source files into this branch. It does **not** delete an original game or copy accounts/secrets. Resolve any recorded `docs/game3d-source-snapshot.json` missing-cross-app imports and type/package conflicts; run native tests, Game 3D Play, world collisions, 3D viewer/camera, character saves, two-client multiplayer, live GLB animation, and server/API ownership tests **before merging**. If clean:

```bash
git add -A
git commit -m "feat(game3d): complete Book source and asset import"
git push origin migration/game3d-book-adam-eve-20261112
```

Verify the target app's GitHub connection/webhook and deployment. Do not declare it live until the actual target preview works and the authorized deployment completes.
