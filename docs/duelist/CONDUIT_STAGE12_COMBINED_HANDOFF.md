## Shared simulation preparation
New conduitMatchAdapter.mjs derives a JSON-serializable trusted manifest from the assembled map registry, spawns, pickups and graph. The pure adapter imports no renderer or DOM. It provides identical support/standing/collision/swept movement, pad launch, validated navigation, pickup placement inspection and match-local spawn reservations. Independent host/prediction test checks exact manifest equality across low/high quality, deterministic negative-elevation movement, pad velocities and reservations. Manifest is build-time trusted data only, never accepted from a player. It is not yet a generated deployed server asset; no existing multiplayer host uses it. A future server integration must pin a digest/version, require client compatibility, own collision authority/LOS/rays, combat, bot actions, recovery, pad events, pickup grants/respawns, reservation lifecycle, stealth and replication; resolve invalid/expired reservations and out-of-bounds/fall behavior. Existing TDM remains Meridian, and FFA remains unchanged. No client-supplied hidden positions or authority changes.
