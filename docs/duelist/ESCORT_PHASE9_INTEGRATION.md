# Transport / Escort: mountain canyon import

Original Phase 9 archived as escort-phase9-source.html. The existing shared game renderer mounts the imported map and actual payload mesh; no iframe or separate application. Terrain, sky, river and waterfall animations are visual-only. Route keeps the 15 control points and 4 primary platform locations, with elevation blending at junctions and small landing/bypass repairs. Spawn data and collision meshes are generated by scripts/audit-escort-phase9.mjs; regenerate the navigation graph with scripts/build-escort-nav.mjs. The production map module is the source of repaired geometry; the extraction script intentionally refuses to overwrite it.

The server uses 432m constant-distance payload motion, 3.5 m/s, radius 9m, Point A activation, physical checkpoint milestones, five progressive spawn zones (54 positions), 300s initial timer and 60/90/90s bonuses. Existing overtime is retained. Protocol 17 refreshes native room identities while retaining public room IDs. No changes to other arena geometries.

Automated geometry and server tests cover all 54 spawns, 12 prototype audit categories, sampled oriented vehicle clearance and route walking, match objective progression and multiple clients. Physical GPU/device frame rate and visual inspection remain separate from these headless tests.
