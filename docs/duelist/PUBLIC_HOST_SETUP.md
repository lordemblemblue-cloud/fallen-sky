# Public arena host (review before deployment)
The Base44 browser currently has no VITE_DUELIST_WS_URL; the old Game 2 relay speaks a different protocol. This isolated host is for anonymous public battle arenas only, with server-generated ephemeral guest identities and server-authoritative match simulation. No Base44 credentials or durable account progression. Story multiplayer is not offered by this host. Existing account server is unchanged.
 
Deploy only after focused tests and review of parent PR #333. Build from repository root using server/duelist/Dockerfile.public; configure DUELIST_PUBLIC_ORIGINS to the exact HTTPS published game origin and actual preview iframe origin, not the editor shell origin. One replica, TLS at edge, healthcheck /status, network-level connection and request limits before public exposure. Configure the actual generated wss://HOST/ws/duelist URL as VITE_DUELIST_WS_URL in the Base44 web build. Verify GET /lobby and two independent clients selecting the same room ID. Do not use the old Game 2 URL or fabricate rows. The anonymous endpoint is intentionally public; origin checks are not authentication or DDoS protection. Resource caps are preliminary, not load certification.
