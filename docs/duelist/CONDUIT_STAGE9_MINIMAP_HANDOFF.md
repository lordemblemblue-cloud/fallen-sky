# The Conduit — Stage 9 three-level minimap

## Scope
Standalone React SVG minimap and a renderer-independent data model. The model derives public floor silhouettes (including courtyard cutouts), annuli, stair flight locations, building names, pickup locations and jump pads directly from the approved map collision registry/config. Not a navigation certificate. No live HUD placement or TDM registration. Existing HUD, renderer, class rules, collision and network protocol untouched.

## Behavior
Three tiers T0 Undercroft, T1 Courtyard, T2 Ring & Crown. Auto follows authoritative support tier if provided; otherwise elevation heuristic at -2.5 and 3.2 m. Keep previous tier during airborne motion when grounded=false is supplied. Manual floor tabs and AUTO. North-up SVG, local heading in radians clockwise from north (host converts from game yaw). Teammate markers need explicit mapVisible permission and alive=true; other-tier allies have an up/down marker. Enemies need explicit mapVisible and enemyReveal, alive=true, and selected floor match. Feed only presentation-authorized actors, not raw network opponents; client filtering is not a server security boundary. No enemy markers generated from audio or stale positions. Up to 100 nonself markers plus player. Pickup states are optional authoritative availability/remaining seconds; unknown stays outlined, never assumed available. No ticking independent timers. Future vents appear only when supplied as both mounted and certified and within map bounds; current Stage 3 prototypes are not displayed as usable. Vertical shortcuts are not yet depicted; add after certification.

## UI and performance
Neutral graphite, restrained gold/cyan, small SVG with no second 3D renderer, canvas or loop. Static geometry memoized by arena and certified route array identity (host must keep references stable). Host supplies throttled presentation snapshots and mounts in unused HUD space, respecting mobile joystick, abilities, chat, objective and F11 layout. Compact landscape styling; actual touch sizing/position and visual readability require device testing. No global HUD edits.
