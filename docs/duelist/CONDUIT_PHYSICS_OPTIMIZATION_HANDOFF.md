# Conduit performance follow-up: indexed physics
PR #369 is merged, and its combined run 45679560285 passed all Conduit tests, manifest export/checksum, and production build; repository lint failed. Neither the active TDM nor FFA host has been switched to Conduit. Do not equate source merge with live activation.

This draft adds a conservative 4 m XZ index for immutable trusted collision snapshots. OBB/cylinder bounds include up to 1 m query-radius expansion, rotated box/ramp extents, original registry order, and immutable per-cell arrays. Discs, annuli, cutouts and exact narrow-phase tests stay intact. Mutable registries, unsupported radii, invalid or excessively broad shape bounds use full scans. Index allocations capped; WeakMap ownership allows reclamation with the snapshot. Route resolver snapshots finished geometry once (its existing route cache already assumes static architecture). No change to geometry, movement rules, render backend, server authority or game settings.

Exact committed-source isolated JavaScript assertion harness: all 11 fixture groups passed (2 broadphase + 6 traversal + 3 route resolver). Synthetic grid with 300 OBBs, 1 ramp, 1 cylinder and 2400 deterministic radius-.4 query points: 724800 full-scan candidate visits vs 6215 indexed visits (99.14% fewer for these three indexed shape categories); not wall-clock speed or real arena FPS. New assembled parity test compares every navigation anchor and adjacent points, 32 spawn movement traces, and requires >=75% fewer candidate visits on the actual map. Existing assembled traversal tests remain unchanged. GitHub combined and traversal CI are required; real-map results and hardware metrics are not yet verified.

Release criteria: combined regression/build/lint; live trusted map registration for both modes; server/client physics, spawn, ray/LOS, recovery, pad and pickup synchronization; mounted and certified shortcuts and drop routes; physical WebGPU/WebGL fallback testing in desktop Edge/Chrome and landscape mobile with 60 FPS target (16.67 ms frame budget), median/p95/p99 frame time, 1% lows, actual draw calls, device memory and loading time; real multiplayer load at existing capacities and coordinated higher-capacity tests. No claims of 100% optimization or guaranteed FPS, no merge/deployment without review and passing validation.
