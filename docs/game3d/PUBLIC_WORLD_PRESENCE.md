# Drop-in Fallen Sky world presence (draft)
 
The main game currently uses guest-only entry. The legacy PlayerState/WebRTC presence manager needs an authenticated user ID, so it cannot honestly claim guest players are connected. Do not fake a Base44 identity or open PlayerState writes. This isolated service supplies server-issued ephemeral presentation IDs only.
 
- Single shared room, 20 connected sockets, immediate admission, no queue. Region/streamed-area filtering hides players in other scenes. Only finite position, facing and bounded animation names are relayed; client identity, account data, rewards and combat are never accepted. Rate and payload limits, origin allowlist, slow-consumer/idle cleanup. The world remains local/offline when not configured. No server-authoritative movement or shared quest/boss/combat state is claimed. Guest avatars use existing remote-player presentation and generic labels.
- Run from full checkout: install the existing dependencies under server/game3d; run `GAME3D_PRESENCE_ORIGINS=https://your-app.example node server/game3d/publicPresenceEntry.mjs` on one isolated Node host with TLS termination and network-level rate limiting. Health: /health. WebSocket: /ws/world-presence. Set VITE_GAME3D_PRESENCE_WS_URL to the actual wss URL for the web build. Do not expose the private duel/quest service or any signing secrets. Origins are a browser restriction, not authentication against arbitrary network clients. A full or unreachable service is shown as a connection failure; no fabricated players or automatic waiting queue. No production host configured by this PR.
- Verify two physical browsers after character selection, movement/rendering, area transitions, disconnect/reconnect, full capacity, malformed packets, mobile performance and no privileged actions. Do not claim shared PvE, PvP or persistence until independently implemented and reviewed.
- Duelist Adventure: #334 is merged; #333 expands capacity and requires secure public admission/host review. Classic Game 2 already has a real server catalog and browser; do not duplicate it or blindly relax authentication. Marcus Flow 1 original app repo was inaccessible; its migrated Game 2 source is inspectable in this repo. Distinct hosting/protocols must remain isolated.
