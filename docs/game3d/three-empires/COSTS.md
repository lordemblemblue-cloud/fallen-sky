## The first test, 2026-11-22

The owner approved 26 credits for one test character, asked for as Elder Maren. The shape came back usable; the colour step turned it into a white-bearded old man in a green vest. Rather than pay again blindly, the same model was finished as **Bram the lamplighter**, whom it fits. Elder Maren is still to be made.

What it produced: one mesh of 12,635 triangles, one material, a 24-bone skeleton, and the clips Idle, Talk and Walk. Packed for the game it is `public/game3d/threeroads/cast/bram_lamplighter.glb`, 0.82 MB with a 1024 px texture: one draw call. The shared stand-in figure the cast wears today is four to five draw calls and about 20,000 triangles.
